# Background Image Requirements

To match the flyer design properly, you'll need the following images:

## 1. diagonal-pattern.png
- A subtle light diagonal pattern image for the main background
- Should be very light, with thin lines to create a sophisticated background texture
- Recommended resolution: 1920x1080px

## 2. pattern-overlay.png
- Colorful pattern for the bottom border section
- Should match the geometric pattern visible in the bottom of the flyer (colorful dots and shapes)
- Recommended resolution: 1920x200px

## 3. logo.png
- The official GOFAMINT logo as seen in the flyer
- Place this file in the public directory (not in the backgrounds folder)
- Should be a transparent PNG with the red flame and blue circular logo
- Recommended resolution: 160x160px

## Development Approach
For development purposes, you can:
1. Extract these elements from the flyer you shared
2. Create similar designs using graphic design software
3. Use placeholder graphics and replace them with official assets later

Each image should be properly optimized for web use while maintaining visual quality.
